# Gestión de Oficinas (Java)

Proyecto Java para la gestión de oficinas: empleados, oficinas, reservas y recursos.

## Objetivo
- Proveer una API REST y/o una UI mínima para administrar oficinas y sus recursos.

Este repositorio contiene una aplicación Java (p. ej. Spring Boot) para gestionar oficinas y sus recursos. Aquí encontrarás instrucciones para ponerla en marcha localmente, ejemplos de uso y cómo colaborar en el proyecto.
